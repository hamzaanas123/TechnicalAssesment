## Project Overview
This is a Flutter e-commerce app that displays a **product list** and **product detail** screens.  
Features include:

- Responsive UI for different mobile screen sizes
- Light and dark theme support
- Product filtering by category
- Product details including images, description, price, discount, stock, rating, and QR code
- Image carousel with auto-slide
- Shimmer effect while loading products
- Clean UI design using Google Fonts
